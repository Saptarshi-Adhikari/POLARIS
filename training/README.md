# Offline Training Pipeline for POLARIS / ASTRALIS Nav-OS

This directory contains the Python offline training and evaluation pipeline for autonomous ship navigation models trained on simulation datasets generated by POLARIS.

## Directory Structure

```
training/
├── README.md             # Pipeline overview and usage guide
├── dataset_loader.py     # Deterministic 70/15/15 episode-level data split and JSONL loader
├── preprocess.py         # State observation normalization and feature vector creation
├── train.py              # PyTorch / Scikit-Learn training loop (state -> target heading / rudder)
├── evaluate.py           # Offline evaluation suite comparing baseline vs. learned controller
├── models/               # Saved model checkpoints
└── checkpoints/          # Training iteration checkpoints
```

## Dataset Splitting Policy

Datasets are split **strictly by episode ID (seed)**, never by individual frames:
- **Train**: 70% of episodes
- **Validation**: 15% of episodes
- **Test**: 15% of episodes

This prevents temporal data leakage between consecutive frames of the same navigation trajectory.

## Pipeline Workflow

To generate, validate, split, train, and evaluate autonomous navigation models, execute the following command sequence:

### 1. Generate Dataset
```bash
node scratch/generate_training_lab_dataset.js
```

### 2. Validate Dataset
```bash
node scratch/phase66_forensics.js
```

### 3. Split Dataset
```bash
python training/dataset_loader.py --dataset datasets/v3
```

### 4. Train Model
```bash
python training/train.py --dataset datasets/v3 --epochs 50 --batch-size 64
```

### 5. Evaluate Model
```bash
python training/evaluate.py --model training/models/latest.pt --dataset datasets/v3
```

### 6. Compare Model vs Baseline
```bash
python training/evaluate.py --model training/models/latest.pt --baseline scratch/baseline_evaluation.json
```
