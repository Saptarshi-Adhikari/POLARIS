# THIRD PARTY NOTICES & REFERENCE ACKNOWLEDGMENTS

This project incorporates architectural concepts and interface designs inspired by the following open-source projects:

## 1. OpenDrift
- **Reference**: https://github.com/OpenDrift/opendrift
- **License**: GPL-3.0
- **Usage**: Conceptual reference for multi-component ocean trajectory modeling (decomposing iceberg drift into current, windage, and observed velocity components). No source code was directly copied.

## 2. IcebergShipDetection
- **Reference**: https://github.com/eikeschuett/IcebergShipDetection
- **License**: MIT
- **Usage**: Architectural reference for SAR object detection workflows (Sentinel-1 candidate extraction and classification tags).

## 3. SAR-SHIP-DETECTION
- **Reference**: https://github.com/ioEclipse/SAR-SHIP-DETECTION
- **License**: MIT
- **Usage**: Reference for object tracking and target correlation between catalogued icebergs and radar detections.

## 4. NTNU COLAV Simulator
- **Reference**: https://github.com/ntnu-itk-autonomous-ship-lab/colav-simulator
- **License**: MIT
- **Usage**: Conceptual reference for scenario-based benchmarking and COLREG collision avoidance evaluation.

## 5. DNV Maritime Schema
- **Reference**: https://github.com/dnv-opensource/maritime-schema
- **License**: MIT
- **Usage**: Format reference for exporting POLARIS scenarios and avoidance evaluation outputs to standardized DNV-compatible JSON schemas.
