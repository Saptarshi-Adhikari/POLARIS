# ML Sea-Ice Concentration Forecasting

This document outlines the architecture, model pipeline, dataset generation, and operational integration details for the ASTRALIS Sea-Ice Concentration Forecast system.

---

## 1. MACHINE LEARNING MODEL PIPELINE

- **Model Type**: Scikit-Learn `MultiOutputRegressor(RandomForestRegressor)`
- **Horizons**: +6 hours, +12 hours, and +24 hours forecasts.
- **Input Features**:
  - `x`, `y` (Current coordinates)
  - `current_ice` (Simulated telemetry sea-ice concentration percentage)
  - `temperature` (Simulated environmental thermal state)
  - `wind_speed`, `wind_dir` (Winds vectors affecting ice boundary shifts)
- **Output Targets**:
  - `ice_6h` (Projected concentration at +6 hours)
  - `ice_12h` (Projected concentration at +12 hours)
  - `ice_24h` (Projected concentration at +24 hours)

---

## 2. TRAINING METHOD & ACCURACY

- **Dataset**: `backend/sea_ice_data.csv` (2,000 samples generated by evaluating thermal freezing equations with Gaussian perturbations).
- **Fitting**: Standard 50-estimator Random Forest.
- **Save State**: Serialized model is saved to `backend/model_sea_ice.joblib`.
- **Metrics**:
  - Train $R^2$: `0.9856`
  - Test $R^2$: `0.9131`

---

## 3. API ENDPOINTS

- **POST `/predict/sea-ice`**
  - **Request Body**:
    ```json
    {
      "x": 1200.5,
      "y": 1400.2,
      "current_ice": 0.45,
      "temperature": -15.0,
      "wind_speed": 35.0,
      "wind_dir": 180.0
    }
    ```
  - **Response Body**:
    ```json
    {
      "status": "ONLINE",
      "current_ice": 0.45,
      "ice_6h": 0.52,
      "ice_12h": 0.58,
      "ice_24h": 0.69,
      "confidence": 0.88
    }
    ```

## 4. NAVIGATION & AUTONOMOUS CONTROL INTEGRATION

- **Path Traversal Cost Weighting**: The A* pathfinder extracts maximum forecasted sea-ice values across the +6h, +12h, and +24h windows inside [`aiNavigator.js`](file:///c:/Users/Saptarshi/Desktop/MainFolder/Hackathon/shipnav/v2/ASTRALIS_SIMULATION/src/js/ai/aiNavigator.js). Cells with high forecasted ice concentrations receive significantly higher traversal costs, forcing routes around frozen clusters.
- **Autonomous Throttle Adjustments**: The [`AutonomousController`](file:///c:/Users/Saptarshi/Desktop/MainFolder/Hackathon/shipnav/v2/ASTRALIS_SIMULATION/src/js/ai/autonomousController.js) checks predictions:
  - If forecasted concentrations exceed 60%, it limits target speeds to 10 knots and flags `reroute = true` to force A* replanning.
  - If forecasted concentrations exceed 40%, it limits target speeds to 14 knots for safety.
