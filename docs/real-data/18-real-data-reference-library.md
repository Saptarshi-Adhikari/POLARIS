# 18 — POLARIS Real Data Reference Library

## Annotated Technical Reference Library

This reference library contains verified external documentation links, data providers, and regulatory standards relevant to POLARIS Real Data Mode:

1. **USNIC Antarctic Iceberg Catalogue**
   - **Provider**: U.S. National Ice Center (NOAA / U.S. Navy / USCG).
   - **Link**: [https://usicecenter.gov/Catalog/AntarcIceberg](https://usicecenter.gov/Catalog/AntarcIceberg)
   - **Purpose**: Primary historical & NRT Antarctic iceberg tracking catalog.
   - **POLARIS Status**: `[CURRENT - IMPLEMENTED]`

2. **USNIC Main Resources**
   - **Provider**: U.S. National Ice Center.
   - **Link**: [https://usicecenter.gov/Resources/Main](https://usicecenter.gov/Resources/Main)
   - **Purpose**: Ice charts, sea-ice extent products, and polar weather resources.
   - **POLARIS Status**: `[CURRENT - IMPLEMENTED]`

3. **Copernicus Marine Service**
   - **Provider**: European Union Copernicus Programme.
   - **Link**: [https://data.marine.copernicus.eu/](https://data.marine.copernicus.eu/)
   - **Purpose**: Global ocean physics reanalysis (currents, sea surface temperature, sea ice).
   - **POLARIS Status**: `[CURRENT - IMPLEMENTED]`

4. **Copernicus Global Ocean MultiObservation Current Product**
   - **Provider**: Copernicus Marine Service.
   - **Link**: [https://data.marine.copernicus.eu/product/MULTIOBS_GLO_PHY_MYNRT_015_003/services](https://data.marine.copernicus.eu/product/MULTIOBS_GLO_PHY_MYNRT_015_003/services)
   - **Purpose**: Near-Real-Time and historical ocean current vector products.
   - **POLARIS Status**: `[CURRENT - IMPLEMENTED]`

5. **Copernicus Global Ocean Physics Reanalysis**
   - **Provider**: Copernicus Marine Service.
   - **Link**: [https://data.marine.copernicus.eu/product/GLOBAL_MULTIYEAR_PHY_001_030/services](https://data.marine.copernicus.eu/product/GLOBAL_MULTIYEAR_PHY_001_030/services)
   - **Purpose**: Multi-year ocean current hydrodynamics reanalysis dataset.
   - **POLARIS Status**: `[CURRENT - IMPLEMENTED]`

6. **ERA5 Reanalysis (ECMWF)**
   - **Provider**: European Centre for Medium-Range Weather Forecasts.
   - **Link**: [https://www.ecmwf.int/en/forecasts/datasets/era5-hourly-data-single-levels-1940-present](https://www.ecmwf.int/en/forecasts/datasets/era5-hourly-data-single-levels-1940-present)
   - **Purpose**: Hourly 10m wind velocity fields.
   - **POLARIS Status**: `[CURRENT - IMPLEMENTED]`

7. **OpenStreetMap (OSM)**
   - **Provider**: OpenStreetMap Foundation.
   - **Link**: [https://www.openstreetmap.org/](https://www.openstreetmap.org/)
   - **Purpose**: Geographic basemap & coastline vector geometry.
   - **POLARIS Status**: `[CURRENT - IMPLEMENTED]`
