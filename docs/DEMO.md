# Demo Walkthrough

### 30 SECOND PITCH
"Welcome to Astralis Nav-OS. This digital twin simulates navigating dangerous polar waters. Watch as I change the wind speed (drag slider), and see the icebergs alter their drift patterns. When a hazard crosses our path, the AI immediately reroutes the ship to safety."

### 2 MINUTE DEMO
1. Start at the default view. Point out the vector field (ocean currents) and the ship's pre-calculated route.
2. Click an iceberg to open the Iceberg Inspector telemetry panel.
3. Click "ADD ICEBERG" and drop a "MEGA" iceberg directly in the path of the ship.
4. Watch the red "REROUTE ALERT" trigger and the path recalculate.
5. Hit the "100X" time warp button to show the simulation running faster.

### 5 MINUTE TECHNICAL DEMO
*Same as 2 minute demo, plus:*
1. Click the "STORM EVENT" button. Explain how extreme weather inputs force massive trajectory recalculations.
2. Open the "SYNTHETIC DATA" drawer. Click "Generate 5 Scenarios". Explain that (conceptually) this engine can simulate thousands of these events to create training data for future AI models.

### WHAT IS REAL
- The math calculating the shortest path avoiding the circles (A*).
- The vector math moving the icebergs.
- The UI interactivity.

### WHAT IS SIMULATED / FAKED
- The ocean currents and weather (they are just sine waves and sliders).
- The "System Risk" and "Fuel Efficiency" numbers (they are heuristics).
- The Synthetic Data logs (they are hardcoded strings, no data is saved).

### WHAT IS PLANNED
- Replacing the sine waves with OpenDrift satellite data.
- Replacing the A* pathfinding with trained ML models.

### QUESTIONS JUDGES MAY ASK
- **Q: Is it pulling real satellite data?** 
  - **Truthful Answer:** "Not in this prototype. This is a deterministic simulation to prove the UI and routing concept. The backend integration for live Sentinel data is Phase 2."
- **Q: Is this a real AI?**
  - **Truthful Answer:** "The current routing engine uses a heuristic search algorithm (A*). We plan to use the synthetic data generated by this engine to train actual ML models in the future."
