# ASTRALIS Nav-OS Canonical Track Schema Specification v1.0.0

## Data Provenance
Every observation record and dataset manifest MUST contain a `data_provenance` attribute:
- `synthetic`: Generated by simulation / syntheticDataGenerator.
- `real`: Collected from operational sensor feeds / satellite / AIS.
- `mixed`: Combination of real trajectories with synthetic augmentation.
- `unknown`: Unverified legacy data.

## Fields
- `schema_version`: "1.0.0"
- `track_id`: Unique identifier string for an iceberg trajectory.
- `timestamp_utc`: ISO-8601 UTC timestamp string.
- `x_m`, `y_m`: Local projected coordinates in meters (+X East, +Y South).
- `sea_ice_concentration`: Concentration value bounded in `[0.0, 1.0]`.
